# MAIA - MMSGI AI Assistant

MAIA (MMSGI AI Assistant) adalah aplikasi AI internal perusahaan yang membantu karyawan mendapatkan informasi, mencari dokumen, dan berinteraksi dengan knowledge base perusahaan.

## Technology Stack

- Python 3.12
- FastAPI
- Llama.cpp
- Qwen2.5 GGUF Model
- RAG (Retrieval Augmented Generation)
- HTML/CSS/JavaScript
